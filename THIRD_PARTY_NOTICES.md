## Diagnostic trouble code descriptions

The trouble-code titles in
`core/src/main/resources/io/github/anwo91/phevlink/core/obd/dtc/codes.tsv` (about 3500 generic
OBD-II codes, such as `P0420 Catalyst System Efficiency Below Threshold Bank 1`) were merged from the
two projects below. Reserved entries and codes in manufacturer-controlled ranges were left out.
Spacing and a few obvious typos were normalised. The table was generated by a one-off script that is
not part of the build.

### Original explanations

The plain-English explanations (system, severity, likely causes, checks and drive advice) in
`core/src/main/kotlin/io/github/anwo91/phevlink/core/obd/dtc/` were written for this project. That
includes the hand-written entries for common Outlander PHEV codes and the rules for all other codes.
They are covered by this project's GPL-3.0-or-later license.

They are general guidance only and do not replace a diagnosis by a qualified workshop. The meaning
of a code can differ between manufacturers and model years. Work on the high-voltage system (orange
cables, drive battery, inverters, charger) and on airbags must only be done by trained technicians.

## OBDb

Some manufacturer-specific signal definitions in
`core/src/main/kotlin/io/github/anwo91/phevlink/core/obd/PhevSignals.kt` (the engine ECU service 21 values,
instrument cluster, air conditioning, ABS wheel speeds and AWC groups) are adapted from the OBDb signal set
for the Mitsubishi Outlander.

- Project: OBDb, https://github.com/OBDb/Mitsubishi-Outlander
- File used: `signalsets/v3/default.json` (commit `2a1fef2f4916048bd43ac7f24ae2fe813b6c6099`)
- Copyright: the OBDb contributors
- License: Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0),
  https://creativecommons.org/licenses/by-sa/4.0/. Creative Commons lists GPL-3.0 as a compatible license for
  CC BY-SA 4.0 adaptations, so the adapted definitions are distributed under this project's GPL-3.0-or-later.
- Changes: only a subset was taken (no signals that need a diagnostic session, no diesel/turbo-only or
  4th-generation signals). The definitions were converted from JSON to Kotlin with new ids, names and groups.
  Every adapted signal is marked experimental, because the set was written for the non-PHEV Outlander.
- Test data: the emulator `core/src/main/kotlin/io/github/anwo91/phevlink/core/obd/emulator/FakeElm.kt` and
  `core/src/test/kotlin/io/github/anwo91/phevlink/core/ObdDecodeTest.kt` reuse a few response/expected-value
  pairs from the same repository (`tests/test_cases/2011/commands/`).

## Diagnostic trouble code translations

The fault-code explanations are available in English, Norwegian bokmål, Swedish, Danish and German.
The explanation texts (now in `strings_<lang>.txt` next to `codes.tsv`), the component names
(`components_<lang>.tsv`) and the Norwegian, Swedish and Danish code titles (`codes_nb.tsv`,
`codes_sv.tsv`, `codes_da.tsv`) were written or generated for this project from an original glossary.
They are covered by this project's GPL-3.0-or-later license, and the guidance and safety notes under
"Original explanations" above apply to every language.
